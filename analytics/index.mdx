The Analytics module provides a comprehensive suite of data visualizations and reporting tools built on Recharts. It is organized into eight sub-modules, each accessible via the tab navigation at the top of the analytics section. A separate Sales Ledger module provides detailed loan-level transaction reporting.

## Modules

| Module | Description |
|--------|-------------|
| [Pipeline Analytics](/analytics/pipeline-analytics) | Real-time view of your active loan pipeline -- stage distribution, bottlenecks, velocity between stages, and per-LO breakdowns. |
| [Projections](/analytics/projections) | Forward-looking funding projections with confidence scoring, weekly and monthly breakdowns, and accuracy tracking against actuals. |
| [Funded Loans](/analytics/funded-loans) | Historical analysis of funded loans with multi-year monthly trends, quarterly breakdowns, and loan officer efficiency metrics. |
| [Performance](/analytics/performance) | Loan officer leaderboard with volume rankings, pull-through rates, days to fund, draw balance alerts, and period-over-period comparisons. |
| [Operations](/analytics/operations) | Operational efficiency metrics including lender turn times, SLA-based aging reports, and conversion/fallout analysis. |
| [Planning](/analytics/planning) | Goal setting and progress tracking for volume, units, and revenue targets at the company or individual LO level. |
| [Profitability](/analytics/profitability) | Revenue and margin analysis combining loan revenue, commission payouts, and expenses into net profit calculations. |
| [Custom Metrics](/analytics/custom-metrics) | Build your own KPIs with configurable aggregations, filters, groupings, and visualizations. |
| [Sales Ledger](/analytics/sales-ledger) | Detailed loan-level transaction report with pay period and date range views, summary totals, and CSV export. |

## Navigation

The analytics tab navigation appears at the top of every analytics page. The tabs are:

- **Funded** -- Funded loan analysis and charts
- **Pipeline** -- Active pipeline overview
- **Performance** -- LO leaderboard and rankings
- **Profitability** -- Revenue, cost, and margin analysis
- **Operations** -- Turn times, aging, and conversion
- **Planning** -- Goals and progress tracking
- **Projections** -- Forward-looking funding forecasts
- **Custom** -- User-defined custom metrics

The Sales Ledger is accessible from the main sidebar navigation.

## Shared Filters

Most analytics modules share a common set of filters that narrow the data being analyzed:

| Filter | Available In | Description |
|--------|-------------|-------------|
| **Date Range** | All modules | Start and end dates to scope the analysis period |
| **Loan Officer** | All modules | Filter to a specific loan officer's data |
| **Branch** | Performance, Operations, Profitability | Filter by branch location |
| **Lender** | Operations | Filter by lender |
| **Lead Source** | Operations | Filter by lead source |

When a date range is provided, many modules automatically calculate a comparison period of equal duration immediately prior to the selected range, enabling period-over-period comparisons.

## Data Sources

Analytics pull data from several core tables:

- **Loans** -- The primary data source for volume, revenue, pipeline stages, dates, and status transitions.
- **Employees** -- Loan officer information, branch assignments, and draw balances.
- **Pay Periods / Payroll** -- Commission payout data for profitability calculations.
- **Expenses** -- Operating costs that factor into profitability analysis.
- **Goals** -- Target definitions for the Planning module.
- **Custom Metrics** -- User-defined metric configurations.
